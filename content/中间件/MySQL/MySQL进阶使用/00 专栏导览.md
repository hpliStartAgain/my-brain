# MySQL 进阶使用专栏导览

## 这一列怎么读

这一列写的是应用开发者与 DBA 日常真正会碰到的事：索引怎么建、`EXPLAIN` 怎么读、事务边界划在哪、死锁怎么复现与重试、表怎么设计、什么时候才该分库分表、慢查询体系怎么落地、缓存一致性怎么保证、变更怎么做不停机、高可用怎么选。

与 `MySQL架构与底层原理`（10 篇，运行期判据）的分界：那一列回答"这个指标异常说明什么、该调哪个旋钮"，这一列回答"代码和 DDL 该怎么写"。机制细节在两列都只给一句结论，真正的源码级推导在 `读书笔记-Mysql内核架构`（19 篇）。

与 `Redis/Redis进阶教程/04`（缓存设计模式）的分界：那一列写 Cache-Aside 与三层一致性，这一列 08 篇写"以 MySQL 为源"时数据库这边特有的三类约束。

**技术版本**：MySQL 8.0 / 8.4 LTS。`ALGORITHM=INSTANT` 的可用范围、`mysql_native_password` 的移除、`replica_*` 变量改名这类版本敏感项在篇内标注。
