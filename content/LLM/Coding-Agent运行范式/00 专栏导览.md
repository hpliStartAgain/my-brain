# Coding Agent 运行范式与交互协议 专栏导览

## 专栏定位

本专栏聚焦 **AI Coding/Terminal Agent 的运行范式与交互协议**——从 ReAct 推理-行动循环到 MCP 标准化协议，从 Claude Code/Devin/OpenHands 的架构解构到 Agent 与操作系统的工程化交互接口。理解这些机制，才能搞懂"Coding Agent 是如何读写文件、执行 Bash 命令、与外部通信的"这一核心问题。

本专栏基于 2024-2025 年最新一手资料创作，覆盖 MCP 2025-11-25 规范、Claude Code Dynamic Workflows、Devin 2.0/2.1、OpenHands Event Stream 架构、Cursor Agent Swarm、Anthropic Context Editing 等前沿进展。

## 目标读者

- 希望理解 Coding Agent 内部工作机制的 AI 工程师与架构师
- 需要基于 Claude Code/Devin/OpenHands 做二次开发或集成的开发者
- 对 MCP 协议标准化方向感兴趣的技术决策者
- 想从"会用 Agent"进阶到"理解 Agent 为什么这样设计"的工程师
