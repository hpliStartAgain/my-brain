# 系统性能工程实战专栏

> 本专栏基于两本权威著作的核心内容整合而成：
> - *Systems Performance: Enterprise and the Cloud* (Brendan Gregg, 2nd Edition, 2020)
> - *JVM Performance Engineering* (Monica Beckwith, 2024)
>
> 两书互补：前者聚焦操作系统、内核与硬件层的性能分析方法论；后者深入 JVM 运行时、GC、JIT 与 Java 应用层的性能工程。本专栏将两者按"全栈性能视角"重新组织，从硬件资源到应用运行时打通一条完整的性能分析链路，去除单本书籍的叙事冗余，构建从理论到工程实践的统一知识体系。

---

## 专栏结构

### 第一部分：性能工程认知重建

回答"性能工程是什么、为什么难、如何科学地思考性能问题"。建立贯穿全专栏的方法论基石。

| 序号 | 文章标题 | 核心内容 |
|------|---------|---------|
| 01 | 性能工程的本质：延迟、吞吐与资源饱和的三角 | 性能 vs 性能工程、延迟与吞吐的对偶、为什么性能问题难、USE/RED/工作负载表征方法论、Linux 60 秒快速清单、Java 性能演进的历史包袱 |

### 第二部分：可观测性工具栈

性能分析的前提是"看得见"。这一部分梳理从操作系统到 JVM 的全栈观测工具谱系，讲清楚每种工具的原理、适用场景与边界。

| 序号 | 文章标题 | 核心内容 |
|------|---------|---------|
| 02 | 系统级性能观测：从 /proc 到 perf 与 Ftrace | Counters/Tracing/Profiling 三层模型、/proc 与 sysctl、perf 采样与 PMC 硬件计数器、Ftrace 内核函数追踪、为什么 strace 会拖垮生产应用 |
| 03 | eBPF 与动态追踪：性能观测的革命 | eBPF 原理与安全模型、BCC 与 bpftrace、kprobes/uprobes、动态追踪 vs 静态插桩、eBPF 的能力边界 |
| 04 | JVM 层性能观测：JFR、JMX 与 async-profiler | JFR 原理与事件模型、JMX MBean、async-profiler 的采样机制、统一日志标签体系、JVM 观测与 OS 观测的互补关系 |

### 第三部分：核心资源深度解析

按 CPU、内存、存储、网络四大资源维度,从硬件原理到内核子系统逐层拆解,这是性能分析的主战场。

| 序号 | 文章标题 | 核心内容 |
|------|---------|---------|
| 05 | CPU：运行队列、调度器与 CPU 缓存的性能博弈 | CPU 周期与 IPC、运行队列与调度延迟、超线程竞争、CPU 缓存层级与缓存命中率、Java 线程与 OS 线程的映射关系 |
| 06 | 内存：从 NUMA 与页表到 JVM 堆模型 | 虚拟内存与页表、Paging 与 Swap、Page Cache、NUMA 与内存亲和性、JVM 堆结构、对象内存布局 |
| 07 | 存储 I/O：文件系统、Page Cache 与块设备 | VFS 抽象层、Page Cache 命中率、I/O 调度器、磁盘延迟模型、随机 vs 顺序、fsync 的代价、SSD 与 NVMe 的特性差异 |
| 08 | 网络：协议栈、Buffer 与 RPC 延迟 | 协议栈分层、socket buffer 与队列、中断与软中断、分段卸载、网络延迟拆解、TCP 拥塞控制对性能的影响 |

### 第四部分：JVM 运行时性能

从 OS 层下沉到 JVM 运行时层,讲透 Java"慢启动快稳态"的底层机制、GC 工程化与锁竞争。

| 序号 | 文章标题 | 核心内容 |
|------|---------|---------|
| 09 | JIT 编译与稳态性能：HotSpot 的预热代价 | 解释执行 vs 编译执行、C1/C2 编译器、分层编译、预热机制、deoptimization、为什么 Java"慢启动快稳态"、JIT 与性能基准的关系 |
| 10 | GC 工程化：从分代假设到现代 GC 调优 | 弱分代假设、GC 算法演进（Serial/Parallel/G1/ZGC/Shenandoah）、停顿 vs 吞吐的权衡、GC 日志诊断、GC 选型决策框架 |
| 11 | 锁竞争与并发性能：从 synchronized 到 JOL | 锁升级（偏向→轻量→重量级）、字符串锁与 intern、锁竞争诊断、JOL 对象布局分析、并发性能的边界与反例 |

### 第五部分：实践与边界

从方法论回到工程实践,讲清楚基准测试的陷阱、云环境的新挑战,并以全栈排查案例闭环。

| 序号 | 文章标题 | 核心内容 |
|------|---------|---------|
| 12 | 基准测试方法论：JMH 与系统级 benchmark 的陷阱 | 微基准的典型陷阱、JMH 用法与注解、预热与 Dead Code Elimination、Blackhole、系统级压测的负载模型、基准测试的伦理 |
| 13 | 云环境与异构硬件：性能工程的新边界 | 虚拟化开销、嘈杂邻居、CPU steal time、容器 cgroup 资源限制、异构硬件（GPU/AI 加速）、Project Valhalla 值类型的未来 |
| 14 | 全栈性能排查实战：从告警到根因的方法论闭环 | 60 秒清单实操、USE 方法跨层应用、OS→JVM→应用层逐层下钻、案例复盘、性能排查的思维陷阱 |

## 阅读建议

- **线性阅读**：按序号线性阅读，从方法论到资源深挖再到 JVM 运行时,形成完整全栈视角。
- **跳读排查**：遇到具体性能问题时,直接跳转对应资源章节(05-08)或 JVM 章节(09-11),再回到 01 复习方法论。
- **工具查阅**：文章 02-04 可作为工具速查手册,排查时随时回查。
