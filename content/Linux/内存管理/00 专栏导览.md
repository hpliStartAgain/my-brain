# Linux 内存管理硬核深度解析 · 专栏导览

## 这一列怎么读

内存是 Linux 里唯一"看得见却算不清"的资源：`free` 会骗你、RSS 会重复计算、容器里的三套账彼此不同。本列按一次内存访问的旅程组织——虚拟地址怎么翻译（01）→ 物理页怎么分配（02）→ 缺页时发生什么（03）→ 文件内容怎么进内存（04）→ 不够了怎么回收（05）→ 回收不动时怎么换出（06）→ 换不出来时杀谁（07）→ 怎么用大页减少翻译开销（08）→ 容器里怎么隔离（09）→ 出问题用什么工具看（10）。

每一篇都写到"这个数字该怎么读、这个参数调大调小各付什么代价"，不停留在机制介绍。

**技术版本**：kernel 6.x LTS；cgroup v2 为准，v1 的差异逐处标注。

## 内核版本说明

本专栏以 **Linux Kernel 5.x / 6.x** 为主要参考版本，部分历史演进会回溯到 2.6 内核。所有机制描述均以主线内核为准，发行版（RHEL/Ubuntu/CentOS）的行为可能略有差异，届时会专门说明。
