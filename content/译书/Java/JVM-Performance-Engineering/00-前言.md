# 前言

欢迎阅读这本 JVM 性能工程指南，它凝聚了我作为 Java Champion（Java 冠军）和性能工程师超过 20 年的专业经验。在这些篇幅中，你将踏上一段穿越 JVM 演进的旅程——一段展现 Java 强大能力与架构精湛的叙事。本书精心剖析了 JVM 内部的复杂机制以及性能工程的艺与术，从 HotSpot VM 的内部运作到模块化编程的战略性采用，无所不包。通过主张 Java 在现代计算中的关键角色——从服务器环境到与特殊硬件的集成——它为从业者和爱好者 alike 树立了一盏指路明灯，预示着 JVM 性能工程的下一个前沿。

## 目标读者（Intended Audience）

本书主要面向渴望加深对 JVM 内部机制和性能调优理解的 Java 开发者和软件工程师。它也将极大地惠及系统架构师和设计师，为他们提供关于 JVM 对系统性能影响的深刻洞察。性能工程师和 JVM 调优者将在书中找到优化 JVM 性能的高级技术。此外，计算机科学和工程专业的学生与教育工作者将全面了解 JVM 的复杂性和高级特性。

本着进一步推动性能工程教育的期望，特别是聚焦于 JVM，本书也与编程语言、算法、系统、计算机体系结构和软件工程方面的高级课程相契合。我热衷于促进对这些概念的更深入理解，并兴奋地致力于为课程内容做出贡献，将 JVM 性能工程的原则融入其中，为下一代工程师提供在这一关键技术领域脱颖而出的知识和技能。

本书聚焦于该语言和运行时的复杂性与优势，对 Java 在并发方面的能力、多线程的优势，以及驱动各种环境下峰值性能的精密内存管理机制进行了透彻剖析。

## 本书组织（Book Organization）

**第 1 章 "Java 的性能演进：语言与虚拟机"（The Performance Evolution of Java: The Language and the Virtual Machine）** 专业地追溯了 Java 从 1990 年代中期诞生到 Java 17 中复杂进步的历程。本章突出了 Java 突破性的运行时环境，包括 JVM、庞大的类库和强大的工具集，为 Java 的创新进步、底层技术卓越性、持续进步和灵活性奠定了基础。

亮点包括对 OpenJDK HotSpot VM 变革性的垃圾回收器（GC）和精简的 Java 字节码的分析。本节展示了 Java 对性能的执着，呈现了先进的 JIT 编译和前沿的优化技术。此外，本章还探讨了 HotSpot VM 的 Client 与 Server 编译器之间的协同关系及其动态优化能力，展示了 Java 对敏捷性和效率的持续追求。

另一个焦点是对 OpenJDK 内存管理及其 HotSpot GC 的探索，特别强调了"弱分代假设"的采用。这一概念支撑了 HotSpot 中垃圾回收器的效率，通过按需使用并行和并发 GC 线程，确保峰值内存优化和应用响应能力。

本章在技术深度与可读性之间保持了平衡，使其既适合经验丰富的 Java 开发者，也适合 Java 新手。实用的示例和代码片段贯穿其中，为理解所讨论的概念提供动手实践。

**第 2 章 "Java 类型系统演进的性能影响"（Performance Implications of Java's Type System Evolution）** 无缝地延续了第 1 章的性能焦点，深入探讨了 Java 的核心：其不断演进的类型系统。本章探索了 Java 的基础元素——基本类型和引用类型、接口、类和数组——这些在 Java SE 5.0 之前支撑了 Java 编程。

叙述继续展开从 Java SE 5.0 开始的变革性增强，例如泛型的引入、注解和 VarHandle 类型引用——这些都在进一步丰富该语言。本章重点关注了最近的添加，如 switch 表达式、密封类和备受期待的记录（records）。

特别关注了 Project Valhalla 的持续工作，审视了现有类型系统的性能细微差别以及未来值类型（value classes）的潜力。本节提供了对 Project Valhalla 持续努力的深入见解，从改进的泛型到基本类型类的概念化。

Java 的类型系统不仅仅是一组类型——它反映了 Java 对多样性、效率和创新的承诺。本章的目标是阐明类型系统的过去、现在和前景广阔的未来，促进对其复杂性的深刻理解。

**第 3 章 "从单体 Java 到模块化 Java：回顾与持续演进"（From Monolithic to Modular Java: A Retrospective and Ongoing Evolution）** 广泛涵盖了 Java 平台模块系统（JPMS）及其对模块化编程的突破性影响。本章标志着 Java 向模块化时代的大胆转型，从模块的基本探索开始。它提供了创建、编译和执行模块的实践指导，即使是该领域的新手也能轻松上手。

本章突出了 Java 从单体 JDK 向模块化框架的转型，反映了 Java 对不断演进的需求的适应性以及对创新的承诺。本章的一个突出部分是使用 JDK 17 进行模块化服务的实际实现，它深入探讨了模块交互的复杂性，从服务提供者到消费者，并通过可运行的示例加以丰富。本章涉及关键概念，如实现细节的封装和 JAR hell 的挑战，说明了 Jigsaw 层如何在模块化景观中提供优雅的解决方案。

为进一步丰富这一探索，本章与 OSGi 进行了富有洞察力的比较，突出了它们的相似之处和区别，以使读者全面理解 Java 的模块化系统。诸如 `jdeps`、`jlink`、`jdeprscan` 和 `jmod` 等基本工具的引入，作为模块化生态系统的核心组成部分，都配有详尽的解释和实用示例。这种方法使读者能够在其开发工作中有效地利用这些工具。

本章最后反思了 JPMS 的性能细微差别，并展望了 Java 模块化演进的未来，邀请读者思考其潜在影响和发展。

**第 4 章 "统一 Java 虚拟机日志接口"（The Unified Java Virtual Machine Logging Interface）** 深入探讨了软件开发中至关重要却常被低估的日志世界。本章首先强调了 Java 中统一日志系统的必要性，探讨了分散的日志系统所带来的挑战以及统一方法的诸多好处。本章不仅突出了日志系统的统一性和基础设施，还强调了其在监控性能和优化方面的作用。

叙述探索了广泛的日志标签及其特定角色，强调了创建全面且富有洞察力的日志的重要性。在解决辨识缺失信息的挑战时，本章对日志级别、输出和装饰器提供了清晰的理解。这些特性的复杂性得到了细致的审视，并通过实际示例展示了它们在真实场景中的应用。

本章的一个关键方面是异步日志记录的探索，这是提升日志性能同时最小化对应用效率影响的关键特性。这一特性对于寻求在全面日志记录与系统性能之间取得平衡的开发者来说至关重要。

本章最后强调了日志作为诊断工具的重要性，展示了它们在主动系统监控和被动问题解决中的作用。第 4 章不仅突出了 Java 中有效日志记录的力量，还强调了其在构建和维护健壮应用中的重要性。本章强化了 Java 持续演进的主题，展示了日志记录的进步如何显著提升语言在应用开发中的能力和多用途性。

**第 5 章 "端到端 Java 性能优化：工程技术及基于 JMH 的微基准测试"（End-to-End Java Performance Optimization: Engineering Techniques and Microbenchmarking with JMH）** 聚焦于 Java 生态系统中性能工程的本质。本章强调性能不仅仅是速度，更突出其在打造无与伦比的用户体验中的关键作用。本章从性能工程在更广泛的软件开发领域中关键地位的奠基性探索开始，突出了其作为基本质量属性的地位，并揭示了其多层面的层次。

本章精确地描绘了衡量 Java 性能的关键指标，涵盖了从足迹（footprint）到可用性的细微差别，确保读者掌握性能动态的全貌。进一步深入，它探讨了响应时间的复杂性及其与可用性的共生关系。这种审视提供了对应用时间线机制的洞察，精巧地将响应时间、吞吐量以及点缀其中的不可避免的停顿交织在一起。

然而，性能叙事只有在承认硬件的深刻影响之后才算完整。本章解码了硬件与软件之间的共生关系，强调了语言、处理器和内存模型交汇所产生的和谐交响。从内存模型的微妙之处及其对线程动态的影响，到 Java 内存模型的基础原则，本章穿越了并发硬件的迷宫，揭示了并发计算中至关重要的顺序机制。

在理论讨论之外，本章借鉴了二十多年性能优化方面的实践经验。它介绍了性能诊断和分析的系统性方法，提供了方法论层面的见解，以及对子系统和识别潜在性能问题的方法的详细研究。这些方法论不仅对专注于性能优化的软件开发者至关重要，也为理解底层硬件、软件栈与应用性能之间的复杂关系提供了宝贵的见解。

本章强调了结构化基准测试机制的重要性，涵盖从内存管理到特性发布和系统层的评估。这为 Java 微基准测试套件（JMH）——JVM 基准测试的巅峰之作——奠定了基础。从其基础设置到众多特性的复杂性，这段旅程涵盖了编写基准测试的起源、执行过程，并深入了解了基准测试模式、性能分析器以及 JMH 的关键注解。

因此，第 5 章既是端到端 Java 性能优化的综合指南，也是后续章节的发射台。它激发了对不懈优化的热情，并为读者配备了释放 Java 无与伦比性能潜力所需的知识和工具。

**第 6 章 "OpenJDK 中的高级内存管理与垃圾回收"（Advanced Memory Management and Garbage Collection in OpenJDK）** 标志着深入探讨特定 JVM 改进的潜水，展示了高级的性能工具和技术。本章跃入垃圾回收的世界，揭示了确保 Java 应用高效且有效运行的技术和创新。

本章首先概述了 Java 中的垃圾回收基础知识，为后续对线程本地分配缓冲区（TLAB）和提升本地分配缓冲区（PLAB）的详细探索奠定了舞台，并阐明了它们在内存管理中的关键作用。随着深入，本章揭示了优化内存访问的方法，强调了 NUMA 感知垃圾回收的重要性及其对性能的影响。

本章的亮点在于对高级垃圾回收技术的探索。叙述审视了 G1 垃圾回收器（G1 GC），揭示了其革命性的堆管理方法。从理解分区堆（regionalized heap）的优势到优化 G1 GC 参数以达到峰值性能，本节承诺对这一 Java 最先进的垃圾回收器之一提供全面的认知。此外，Z 垃圾回收器（ZGC）作为一项技术奇迹被呈现，展示了其自适应优化技术以及使其成为实时应用中游戏改变者的进步。

本章还提供了对垃圾回收新兴趋势的见解，为未来的发展奠定了舞台。实用性始终处于前沿地位，专门有一节提供了评估 GC 性能的宝贵技巧。从共情各种工作负载（如联机分析处理（OLAP）、联机事务处理（OLTP）和混合事务/分析处理（HTAP）），到综合实时数据集压力和数据生命周期模式，本章为读者提供了有效优化内存管理的工具和知识。本章是 Java 专业人员需要了解高级垃圾回收技术的入门指南，帮助他们驾驭内存管理的地形。

**第 7 章 "运行时性能优化：聚焦字符串、锁及其他"（Runtime Performance Optimizations: A Focus on Strings, Locks, and Beyond）** 致力于探索 Java 运行时性能的关键方面，特别是在字符串处理和锁同步领域——这两个领域对于高效的应用性能至关重要。

本章卓越地采用了全面的方法来揭开这些 JVM 优化的神秘面纱，通过详细的底层分析——利用从字节码分析到内存和基于采样的性能分析，再到收集被分析方法调用栈视图的一系列分析技术——来丰富读者的理解。此外，本章利用 JMH 基准测试来凸显这些优化带来的实际改进。`async-profiler` 在方法级洞察上的实际应用，以及 NetBeans 内存分析器的使用，进一步增强了读者对 JVM 增强功能的细粒度理解。本章旨在测试和阐明优化措施，为读者提供有效使用这些工具的综合方法，从而建立在第 5 章讨论的性能工程方法论和流程之上。

旅程继续，对 Java 中的字符串优化进行了广泛回顾，突出了多个 Java 版本中的重大进步，然后转向增强的多线程性能，重点介绍了 Java 的线程同步机制。

此外，本章帮助读者驾驭并发的世界，讨论了从每个任务一个线程（thread-per-task）模型到可扩展的每个请求一个线程（thread-per-request）模型的转变。对 Java 的 Executor Service、ThreadPools、ForkJoinPool 框架和 CompletableFuture 的审视，确保了对 Java 并发机制的稳健理解。

本章最后通过虚拟线程一窥并发的未来。从理解虚拟线程及其载体，到讨论并行性以及与现有 API 的集成，本章是 Java 中高级并发机制和字符串优化的实践指南。

**第 8 章 "使用 OpenJDK HotSpot VM 加速达到稳态"（Accelerating Time to Steady State with OpenJDK HotSpot VM）** 致力于优化从启动到稳态的性能，这对于瞬态应用（如容器化环境、无服务器架构和微服务）至关重要。本章强调了最小化 JVM 启动和预热时间对于提升高效执行的重要性，并包含了对 GraalVM 在此领域革命性作用的关键探索。

叙述剖析了 JVM 启动的各阶段以及到达应用稳态的旅程，突出了在各种架构下管理这些阶段期间状态的重要性。对类数据共享（CDS）的深入探讨揭示了共享归档文件和内存映射，强调了在多实例设置中的优势。叙述随后转向了提前（AOT）编译，将其与即时（JIT）编译进行对比，并详述了 HotSpot VM 的 Project Leyden 的变革性影响及其通过 CDS 和 AOT 管理状态的预期能力。这为 GraalVM 及其对 Java 性能格局的革命性影响奠定了舞台。通过利用先进的优化技术，包括静态镜像和动态编译，GraalVM 为广泛的应用提升了性能。对 GraalVM 等前沿技术的探索，以及对 OpenJDK 项目（如 CRIU 和 CraC，它们引入了突破性的检查点/恢复功能）的全面调查，为讨论增添了深度。这一全面覆盖提供了对优化 Java 应用策略不断演进的见解，使本章成为寻求在当今云原生环境中导航的开发者的宝贵资源。

**最后一章，第 9 章 "驾驭特殊硬件：JVM 性能工程的未来"（Harnessing Exotic Hardware: The Future of JVM Performance Engineering）** 聚焦于特殊硬件与 JVM 之间迷人的交汇点，阐明了它对性能工程的激励性影响。本章首先介绍了日益突出的特殊硬件世界，特别是在云环境中。它探讨了此类硬件与 JVM 的集成，强调了语言设计和工具链在这一过程中的关键作用。

通过一系列精心详细的案例研究，本章展示了集成此类硬件加速器的实际应用和挑战。从轻量级 Java 游戏库（LWJGL），到创新的 Aparapi（它桥接了 Java 和 OpenCL），每一项研究都提供了关于这些集成的复杂性和成就的宝贵见解。本章还审视了 Project Sumatra 在该领域的重要贡献，并介绍了 TornadoVM，这是一个专为硬件加速器定制的 JVM。

通过这些案例研究，将特殊硬件与 JVM 集成的共生潜力变得越来越明显，最终引出了 Project Panama 的概述，预示着 JVM 性能工程的新地平线。Project Panama 的核心是 Vector API，一个专为向量计算设计的创新象征。这个 API 不仅仅是关于计算——它关乎确保计算被高效地向量化，并为那些在向量操作上蓬勃发展的硬件量身定制。这确保了开发者拥有为多样化硬件架构优化并行计算的工具。但 Panama 不仅仅是关于向量。外部函数与内存 API（Foreign Function and Memory API）作为一个关键工具出现，是一座允许 Java 与原生库无缝对话的桥梁。这是 Java 对长期以来互操作性挑战的回应，确保 Java 应用能够轻松地与本机代码交互，打破语言壁垒。

然而，这种集成并非易事。从管理复杂的内存访问模式到解读硬件特定的行为，优化的道路上布满复杂性。但这些挑战驱动着创新，推动着可能性的边界。展望未来，本章展示了我对 Project Panama 成为 JVM 互操作性黄金标准的愿景。前景看起来充满希望，Panama 有望重新定义 Java 应用的性能和效率。

这不仅仅是关于当下或不久的将来。JVM 性能工程的世界正处于一场革命的前夜。创新正在敲响我们的大门，等待被拥抱——TornadoVM 的混合 API，以及即将到来的 HAT 工具包和 Project Babylon。

## 如何使用本书（How to Use This Book）

1. **按顺序阅读以获得全面理解**：本书设计为从头到尾阅读，因为每一章都建立在前面章节的知识基础之上。特别推荐给刚接触 JVM 性能工程的读者采用这种方法。
2. **针对特定主题的模块化方法**：经验丰富的读者可能更愿意直接跳到他们感兴趣或面临挑战的章节。目录和索引可以引导你找到相关部分。
3. **实践示例和代码**：全书提供了实践示例和代码片段来说明关键概念。为了充分利用这些示例，鼓励读者自己构建并运行这些代码。（见第 5 条。）
4. **增强理解的视觉辅助**：除了文字解释，本书还运用了多种文本和视觉辅助手段来加深你的理解。
   a. **案例研究**：展示 JVM 性能技术应用的真实场景。
   b. **截图**：描述性能分析结果以及各种 GC 图的可视化输出，这对于理解 GC 过程和阶段至关重要。
   c. **用例图**：描绘系统功能需求的可视化表示，展示不同实体之间的交互方式。
   d. **框图**：勾勒特定 JVM 或系统组件架构的示意图，突出性能特性。
   e. **类图**：各种代码示例的详细面向对象设计，展示关系和层次结构。
   f. **流程图**：逐步引导你完成各种性能优化过程和组件的步骤图。
   g. **时间线**：展示活动的不同阶段或状态变化以及所采取操作序列的可视化表示。
