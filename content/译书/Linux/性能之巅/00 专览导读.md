# 📚 《Systems Performance》 (2nd Edition) 数字化指南

欢迎来到 Brendan Gregg 名著 **《Systems Performance: Enterprise and the Cloud》 (2nd Edition)** 的数字化知识花园。本项目旨在通过 Obsidian 深度链接与结构化笔记，将这本 800+ 页的性能调优圣经转化为可实时查阅的 SRE 运行手册。

## 🗺️ 章节导航 (Roadmap)

我们将全书划分为五个核心阶段，助你从理论走向实战：

### 第一阶段：理论基石 (Foundations)
深入理解操作系统原理与性能分析的方法论。
- [[01 绪论|01 绪论]]：性能分析的概览与 Linux 60 秒快速清单。
- [[02 方法论|02 方法论]]：USE 方法、工作负载表征与钻取分析。
- [[03 操作系统|03 操作系统]]：内核、调度、存储栈与系统调用的底层原理。

### 第二阶段：通用观测 (Observability)
掌握系统提供的原生观测能力与工具体系。
- [[04 可观测性工具|04 可观测性工具]]：工具层级（Counters, Tracing, Profiling）概览。
- [[05 应用程序|05 应用程序]]：应用层性能分析（语言、运行时、垃圾回收）。

### 第三阶段：资源深挖 (Subsystems)
针对 Linux 核心子系统的垂直深度拆解。
- [[06 CPU|06 CPU]]：周期分析、超线程竞争与调度延迟。
- [[07 内存|07 内存]]：虚拟内存、Paging、页缓存与分配算法。
- [[08 文件系统|08 文件系统]]：VFS、缓存管理与延迟拆解。
- [[09 磁盘|09 磁盘]]：存储栈、I/O 调度与硬件特性。
- [[10 网络|10 网络]]：协议栈、分段卸载与排队延迟。

### 第四阶段：现代架构 (Modern Architecture)
适配云计算与虚拟化环境下的性能模型。
- [[11 云计算|11 云计算]]：虚拟化开销、资源限制与嘈杂邻居。
- [[12 基准测试|12 基准测试]]：科学的压测方法与防坑指南。

### 第五阶段：动态追踪三剑客 (Dynamic Tracing)
Linux 高级 SRE 的必备核心技能。
- [[13 perf|13 perf]]：采样剖析与 PMCs 硬件计数器。
- [[14 Ftrace|14 Ftrace]]：内核函数追踪与低开销观测。
- [[15 BPF|15 BPF]]：BCC, bpftrace 与 eBPF 的革命性能力。

### 总结篇
- [[16 案例研究|16 案例研究]]：一个真实的云计算性能调优案例演示。

## 🛠️ 使用建议 (Best Practices)

1. **按图索骥**：遇到具体的系统问题时，直接跳转至对应的子系统章节（如 CPU 或 网络）。
2. **双向链接**：笔记中大量使用了 `[[ ]]` 进行跨章节链接，建议在 Obsidian 中开启 **Graph View** 观察技术点的关联。
3. **脚注查阅**：本数字化版本保留了 Brendan Gregg 的所有脚注和文献引用，提供了丰富的背景信息。
4. **实时工具**：每章末尾通常包含该子系统的常用工具汇总，可作为排查时的命令手册。
