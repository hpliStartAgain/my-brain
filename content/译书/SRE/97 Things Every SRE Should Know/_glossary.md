# 术语对照表（Glossary）

> 本表记录书中关键英文术语的中文译名与说明，供各章翻译时保持一致性。

| 英文原文 | 中文译名 | 说明 |
|---|---|---|
| Site Reliability Engineering (SRE) | 站点可靠性工程 | 保证大规模计算机服务可靠性的工程学科 |
| measure | 测量 | 带有目标的数据采集，而非单纯收集 |
| analyze | 分析 | 运用统计与概率工具从测量数据中提取洞察 |
| decide | 决策 | 基于分析结果确定下一步行动方向 |
| act | 行动 | 执行决策，包括「不采取行动」本身也是一种行动 |
| reflect | 反思 | 以批判但去责备的视角审视已完成的工作 |
| repeat | 重复 | 持续迭代上述循环 |
| blameless | 去责备的 / 无指责文化 | 事后复盘聚焦于系统改进而非个人问责 |
| error budget | 错误预算 | 在 SLO 约束下允许的失败空间 |
| SLO (Service Level Objective) | 服务级别目标 | 量化服务可靠性的内部目标阈值 |
| SLI (Service Level Indicator) | 服务级别指标 | 衡量服务行为的具体可测量指标 |
| SLA (Service Level Agreement) | 服务级别协议 | 与用户或客户签订的可靠性承诺合同 |
| on-call | 值班 / 随叫随到 | 负责响应线上告警的轮班机制 |
| postmortem | 事后复盘 / 故障分析报告 | 故障发生后进行的系统性回顾与学习 |
| incident | 故障 / 事件 | 影响服务可用性或用户体验的线上异常 |
| toil | 琐事 | 重复性、自动化可消除的手工运维工作 |
| observability | 可观测性 | 通过外部输出推断系统内部状态的能力 |
| reliability | 可靠性 | 系统持续按预期运行、满足用户需求的能力 |
| sociotechnical system | 社会技术系统 | 技术系统与人员组织共同构成的整体 |
