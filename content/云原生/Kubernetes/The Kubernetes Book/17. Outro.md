
# 尾声

感谢你阅读本书。现在你已经准备好在云原生世界中大展身手了。

## 封面介绍

我非常喜欢这本书的封面设计，也非常感谢数百位参与投票选出这个设计的人。

封面左侧的 YAML 代码代表了本书的技术性质。中间的 Kubernetes 轮盘图标代表了本书的主题。右侧的垂直符号是云原生图标，采用的是《黑客帝国》电影中数字雨代码的风格。封面上还隐藏着一条用《星际迷航》中的博格语言写成的信息。

> [!NOTE]
> 封面上隐藏着一段用博格语言（Borg language）写成的信息。

## 关于本书图表

Kubernetes 社区提供了一套非常棒的图标资源，存放在以下 GitHub 仓库中：

```
https://github.com/kubernetes/community/tree/master/icons
```

我很喜欢这些图标，并在博客和视频课程中广泛使用。然而，它们在书籍印刷版中的效果并不理想。因此，我为本书专门创建了一套类似的图标。制作这些图标花了很长时间，希望你会喜欢。

我并非试图替代社区图标或贬低它们的价值。只是它们不太适合本书的印刷版本。
