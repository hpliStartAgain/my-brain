### 示例应用和 [[GitHub]] 仓库

本书有一个 [[GitHub]] 仓库，包含贯穿全书的所有应用文件和 YAML 代码。

> [!INFO] 前置要求
> 要跟随示例，你需要安装 git、克隆仓库并切换到 2025 分支。如果你觉得这些听起来令人困惑，请放心——你不需要成为 [[GitHub]] 专家，因为我会始终向你展示需要运行的命令。

#### 安装步骤

**1. 安装 git 到你的电脑**

最简单的方法是在网上搜索 git 安装说明，并按照你的平台（Linux/Mac/Windows...）的指引进行操作。

**2. 克隆仓库并切换分支**

运行以下命令克隆仓库。它会创建一个名为 `TKB` 的新目录，并复制所有文件和文件夹：

```bash
$ git clone https://github.com/nigelpoulton/TKB.git
```

进入新的 `TKB` 目录并切换到 2025 分支：

```bash
$ cd TKB
$ git fetch origin
$ git checkout -b 2025 origin/2025
```

> [!SUCCESS] 完成！
> 恭喜！你已经克隆了本书的 [[GitHub]] 仓库并切换到了 2025 分支。

动手实验部分的大多数命令在 Linux、Mac 和 Windows 上都能运行。但是，其中少数命令需要进行小的修改才能在 Windows 上运行。每当这种情况发生时，我都会解释你需要做的事情。

> [!IMPORTANT] Windows 命令换行处理
> 每次本书使用反斜杠将命令分割成多行时，Windows 用户应选择：
> 1. **移除反斜杠**并将命令放在单行上运行
