数据来源：Zabbix 告警迁移系统（导出时间：2026-05-12）

迁移方案概述

ES 共 43 条规则，已匹配 20 条，未匹配 23 条。

未匹配规则分析：

  • Coordinator HTTP API 探测（20 条，blocked_exporter）：原 Zabbix 对 10 个协调节点逐一做 HTTP 可达性 + 响应时间探测。迁移方案：Categraf http_response 插件，每个节点一条配置（address = "http://es-nodeXX:9200/_cluster/health"），避免逐节点建 Foxeye 规则，可用单条规则 + label 覆盖所有节点。
  • JVM GC 频繁（1 条）：需 ES JMX Exporter 指标，已有 ELK JMX 模板痕迹，需确认 JMX exporter 是否已接入。
  • 节点数变更（1 条）：ES Prometheus exporter 已覆盖 elasticsearch_cluster_health_number_of_nodes，可直接建规则。
