🔧 Categraf 可覆盖2net_response 端口探活 + procstat 进程检测

Ranger 仅有 2 条告警规则，均针对 Ranger Admin 服务的存活性检测，可直接通过 Categraf 覆盖。

规则名称Categraf 方案建议告警条件
Hadoop3 Port 6080 of Ranger Admin is DOWN Categraf net_response 插件 探活 Ranger Admin HTTP 端口 6080；net_response_result_code != 0
Hadoop3 Process of Ranger Admin is DEAD Categraf procstat 插件 检测 EmbeddedServer 或 ranger 进程；procstat_running == 0
