  • 不需要额外部署 Categraf ZooKeeper mntr 插件，5 条核心规则指标已齐备

关键技术突破：__name__=~ 正则解决 Server ID 困境

JMX Exporter 将 MBean 路径中的 server ID 编码进指标名（如 org_apache_ZooKeeperService_ReplicatedServer_id3_OutstandingRequests），导致 7 个实例产生 7 个不同 metric name。

解决方法：VictoriaMetrics 支持 {__name__=~"pattern"} 正则匹配，用 id[0-9]+ 一次覆盖所有实例：

{__name__=~"org_apache_ZooKeeperService_ReplicatedServer_id[0-9]+_OutstandingRequests",busiGroupId="394"}

⚠️ 第三组：Leader 选举检测（1 条，P2 近似方案）

Zabbix 原规则"Server mode has changed"通过 quorumPeer["server.state"] 检测 leader/follower 切换。JMX Exporter 导出了 _Leader 属性（boolean，1=Leader），可通过 changes() 函数检测近期变化：

{__name__=~"org_apache_ZooKeeperService_ReplicatedServer_id[0-9]+_Leader",busiGroupId="394",name3=""}

该指标当前返回 28 series（含多个 name1/name2 维度），需进一步确认 server-level 的 name3="" 过滤是否有效，再建规则。建议同时配合 Loki 日志告警检测选举关键词 "New election"、"LOOKING"。
