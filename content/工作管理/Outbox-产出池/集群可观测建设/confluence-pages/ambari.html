Ambari 告警规则迁移明细

数据来源：Zabbix 告警迁移系统（导出时间：2026-05-12）

迁移方案说明

Ambari 共 3 条告警规则，全部为探活类规则（进程存活 / TCP 端口 / HTTP API 响应），无 JMX 指标需求。

决策：不新增独立 Exporter，通过扩展 Categraf 配置覆盖。

  • 进程存活 → procstat 插件（追加 search_cmdline_substring 配置，平台上报 label 为 search_string）
  • TCP 端口探测 → net_response 插件
  • HTTP API 响应 → http_response 插件

📋 Categraf 配置参考

# 1. 进程存活（追加到 Ambari Server 节点的 procstat 配置）
[[instances]]
search_cmdline_substring = "org.apache.ambari.server.controller.AmbariServer"
gather_total = true
gather_per_pid = false
# 上报 label: search_string="org.apache.ambari.server.controller.AmbariServer"

# 2. TCP 端口探测
[[instances]]
targets = ["10.18.14.33:8080"]
# 上报 label: instance=采集节点IP, target="10.18.14.33:8080"

# 3. HTTP API 响应检查
[[instances]]
