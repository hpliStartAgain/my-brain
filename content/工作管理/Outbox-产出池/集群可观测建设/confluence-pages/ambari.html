数据来源：Zabbix 告警迁移系统（导出时间：2026-05-12）

迁移方案说明

Ambari 共 3 条告警规则，全部为探活类规则（进程存活 / TCP 端口 / HTTP API 响应），无 JMX 指标需求。

决策：不新增独立 Exporter，通过扩展 Categraf 配置覆盖。

  • 进程存活 → procstat 插件（已在集群部署，只需追加 pattern 配置）
  • TCP 端口探测 → net_response 插件
  • HTTP API 响应 → http_response 插件

优势：零新增二进制、零新增部署流程，仅追加 Categraf 配置文件，Foxeye 侧新建对应告警规则引用新指标即可。

📋 Categraf 配置参考

# 1. 进程存活 - 追加到已有 procstat 配置
[[inputs.procstat]]
  pattern = "org.apache.ambari.server.controller.AmbariServer"
  # Foxeye 告警规则: procstat_running{process_name=~".*AmbariServer.*"} == 0

# 2. TCP 端口探测
[[inputs.net_response]]
  address = "ambari-host:8080"
  protocol = "tcp"
  timeout = "5s"
  # Foxeye 告警规则: net_response_result_code{server="ambari-host",port="8080"} != 0

# 3. HTTP API 响应检查
[[inputs.http_response]]
  address = "http://ambari-host:8080/api/v1/clusters"
  method = "GET"
  response_timeout = "10s"
  username = "admin"    # Ambari Basic Auth，建议使用只读账号
  password = "xxxx"
  # Foxeye 告警规则: http_response_result_code{server="ambari-host"} != 0

注意：上述配置需部署在能访问 Ambari Server 的采集节点上（建议 Ambari Server 本机或同网段 Categraf 实例）。HTTP API 鉴权需配置 Ambari 账号，建议使用只读账号。
