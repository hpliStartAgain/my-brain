🚧 第四组：Nginx 告警（14 条，需部署 nginx-exporter）

⚠ Nginx 告警全量 blocked — 需先确认 nginx-exporter 部署范围

Zabbix 通过 Nginx 的 stub_status 和 info 接口采集指标，当前 Foxeye 平台无任何 Nginx 指标。需要选择以下方案之一：

  • 方案 A（推荐）：部署 nginx-prometheus-exporter，通过 stub_status 暴露 Prometheus 指标（nginx_connections_active/waiting/writing/reading），接入 VM + Foxeye
  • 方案 B（降级）：仅用 Categraf http_response 插件做 Nginx 存活探活，放弃连接数/请求速率等业务指标告警
规则名称方案 A 指标方案 B 可否覆盖
Nginx: Service is down（×2）nginx_up == 0✅ http_response 探活
Nginx: Process is not runningnginx_up == 0✅ procstat
Nginx: Service response time is too high（×2）nginx_response_time✅ http_response 响应时间
Nginx: Failed to fetch stub status page（×2）nginx_up == 0⚠ 仅探活，无法区分 stub_status 失联
Nginx: Failed to fetch info data（×1）nginx_up == 0⚠ 同上
Nginx: has been restarted（×1）nginx_restarts_total❌ 无法覆盖
Nginx: High connections drop rate（×2）nginx_connections_waiting/active 变化率❌ 无法覆盖
Nginx: Server response error（×1）nginx_http_requests_total by status_code❌ 无法覆盖
Nginx: Version has changed（×2）nginx_version label 变更检测❌ 无法覆盖

结论：若选方案 B（降级），仅能覆盖 5/14 条，有 9 条无法迁移。强烈建议方案 A（全量 nginx-exporter），需评估 Nginx 节点数量和部署成本。
