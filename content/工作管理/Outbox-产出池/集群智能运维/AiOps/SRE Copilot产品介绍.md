## 一句话定位

SRE Copilot 是一个面向运维工程师的 AI 助手平台，打通了指标（Metrics）、日志（Logs）、告警（Alerts）三大可观测性数据源，让 SRE 可以用自然语言完成故障复盘、告警迁移、远程排障与自动化巡检。

---

## 它解决了什么问题？

|痛点|Copilot 怎么解决|
|---|---|
|Zabbix → Foxeye 告警迁移量大、人工逐条翻译 PromQL 效率极低|AI 批量转换，自动查询指标元数据验证 PromQL 正确性|
|排障时反复跳转 Grafana、终端、告警平台|一个对话窗口同时看指标、查日志、登机器执行命令|
|告警发生后，需要人工查指标、翻日志来定位根因|AI 自动触发根因分析，结合上下文给出诊断建议|
|SSH 远程排障担心误操作，AI 执行命令不可控|建立命令黑白名单与审批流，高危/未知命令需 SRE 审批|
|集群巡检靠经验、靠记忆，容易遗漏检查项|声明式巡检计划，一键执行，自动采集数据并生成图表报告|
|运维知识散落在个人脑中，难以沉淀和共享|Skill 技能库在线编辑且热重载，AI 按场景自动调用 SOP|
|工具能力封闭在 Web 页面里，无法被其他 AI 客户端复用|MCP Server 标准协议暴露，Cursor / Claude Desktop 可直连|

## 核心能力一览

### 1. AI 对话（Chat）

平台的主入口。像使用 ChatGPT 一样，用自然语言描述你的运维诉求，AI 会自动调用合适的工具完成任务。

**你可以这样问：**

- "帮我查一下 HDFS NameNode 的存活 DataNode 数量"
- "把 Zabbix 里 Kafka 相关的告警规则转换成 Foxeye 格式"
- "帮我看看 dnn130160 这台机器的内存使用情况"
- "最近 1 小时 HDFS 有没有 error 日志？"

AI 会实时展示它调用了哪些工具、传了什么参数、拿到了什么结果，全过程透明可追溯。

### 2. 告警事件与 AI 根因分析（Events & Analysis）

告警不再只是一条通知，而是自带“分析报告”的结构化对象。

- **多源汇聚**：统一展示 Zabbix、Ambari、Foxeye 的实时告警事件。
- **AI 根因分析**：可为告警规则开启自动AI分析开关，打开后事件入库时自动触发 AI 分析。AI 会基于指标库和日志上下文，判断故障根因并给出修复建议。
- **对话式复盘**：在事件详情中，你可以通过对话框追加信息（如“看看网络带宽是否也高”），引导 AI 进行深度排查。

### 3. SSH 远程排障与命令审批

通过对话让 AI 登录目标主机执行诊断命令，无需自己开终端，且安全可控。

- **安全管控**：内置命令黑白名单规则引擎。安全命令（top、free、df 等）自动放行；危险命令自动拒绝。
- **审批流程**：当 AI 需要执行未知或复杂的诊断命令时，前端会弹出审批卡片。SRE 可选择“批准（单次/会话/永久）”或“拒绝”，确保每条命令都在可控范围内。
- **审计追溯**：所有命令执行记录完整保留，包括命令内容、输出快照、审批人信息。

![[Pasted image 20260409161539.png]]

### 4. 告警规则迁移与双跑验证（Rules & Dual-Run）

将现有 Zabbix / Ambari 告警规则智能迁移到 Foxeye 平台。

- **AI 批量转换**：一键将 Zabbix 复杂的触发器表达式翻译为 Foxeye 的 PromQL 或 Loki LogQL 格式。
- **语义匹配**：AI 分析新旧规则的语义等价性，自动建立映射关系并给出置信度评分。
- **双跑对比**：迁移后可启动双跑模式，实时对比新老规则的触发情况，确保迁移后的准确率。

![[Pasted image 20260409161548.png]]

### 5. 集群巡检（Inspections）

取代人工逐项检查的低效方式，用声明式的巡检计划自动完成。

- **巡检计划**：定义一组检查项（指标查询、日志查询、告警状态），指定目标集群。
- **异步执行**：一键触发巡检任务，系统并发采集所有数据。
- **报告生成**：自动生成可视化报告，直观展示异常项、趋势图表及 AI 总结摘要。

![[Pasted image 20260409161608.png]]
### 6. 日志查询（Logs）

直接在平台上查询 Loki 日志，专为 SRE 调优。

- **终端体验**：深色背景、等宽字体、黑底白字，完美还原 Linux 终端风格。
- **关键词高亮**：搜索结果中的关键词实时高亮显示，方便快速定位异常点。
- **自然语言查询**：支持“查一下最近 10 分钟 HDFS 的 error 日志”，AI 自动生成 LogQL。
![[Pasted image 20260409161619.png]]


### 7. 运维技能库（Skills）

将团队的运维经验沉淀为结构化的技能文档，AI 在排障时自动“学习”。

- **在线编辑与热重载**：支持 Web 端 Markdown 编辑。保存后立即生效，无需重启服务，AI 的下一次对话就会使用最新的 SOP。
- **内置技能集**：预置 CPU/内存/磁盘/网络诊断、Linux 通用运维、Zabbix 迁移指南等专家级文档。
![[Pasted image 20260409161626.png]]
### 8. 自然语言查指标（NL2PromQL）

不需要记指标名，用中文描述你想查什么。AI 会检索指标元数据库，生成正确的 PromQL 查询语句并展示图表。

## 产品形态

### Web 控制台

访问 `http://10.2.217.250:3000`，左侧导航栏按职责清晰分组：

|分组|页面|说明|
|---|---|---|
|**AI 助手**|对话|主交互入口，自然语言对话|
|**SRE 排障**|告警事件 / 日志查询 / 集群巡检 / 技能库|故障排查、根因分析、自动化巡检|
|**告警迁移**|规则管理 / 服务管理 / 双跑统计|存量规则向 Foxeye 平滑迁移|
|**SSH 管理**|主机清单 / 命令审计 / 命令审批|远程命令管理与安全管控|
|**数据资产**|指标元数据 / PromQL 查询|平台运行的底层知识库|

### MCP Server — AI 工具的“插座”

除了 Web 页面，SRE Copilot 还通过 **MCP（Model Context Protocol）** 标准协议对外暴露所有工具能力。

**这意味着：** 你可以在 **Cursor**、**Claude Desktop** 等开发工具里直接连接我们的平台。在你的 IDE 侧边栏里说“帮我查下这台机器的负载”，本地 AI 就能调用本平台的内网 SSH 工具，结果直接返回到你的代码编辑器里。

#### 配置示例 (Cursor / Open Code)

在 MCP 配置中添加：

```json
{
  "mcpServers": {
    "sre-copilot": {
      "url": "http://<服务器IP>:8081/sse"
    }
  }
}
```

## 安全设计

- **三级命令管控**：全局黑名单 + 主机权限 + 会话审批。
- **人工审批闭环**：危险操作必须经过 SRE 二次确认。
- **全链路审计**：谁、在什么时候、在哪个对话里、在哪台机器上、执行了什么命令、结果如何，全部记录在案。

## 总结

SRE Copilot 致力于消除运维工作中的“心智负担”。它不仅仅是一个聊天的工具，而是连接 Zabbix、Foxeye、Loki、SSH 等孤岛的**中枢系统**。

它的价值在于：**让专家经验可沉淀、让高危操作可管控、让繁琐巡检可自动、让复杂查询自然化。**
