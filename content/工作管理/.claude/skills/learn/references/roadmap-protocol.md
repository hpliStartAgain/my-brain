# 主干道规划协议

本文件定义 ROADMAP 阶段和 GAP_CHECK 阶段的详细规则。

---

## 一、ROADMAP 阶段：规划主干道

### 准备工作

1. **读取用户画像**：读取 `USER.md`，了解用户当前技术基础、学习偏好、已有知识
2. **搜索已有笔记**：在仓库中搜索与主题相关的已有文件，避免重复规划已有内容
3. **获取官方文档结构**：用 WebFetch 获取该技术的官方文档首页或目录页，提取核心章节列表

### 节点设计规则

- **数量**：5-9 个节点，每个节点对应 30-60 分钟的交互学习
- **粒度**：每个节点聚焦一个核心概念或一组紧密相关的概念
- **顺序**：按依赖关系排序，前置知识在前
- **命名**：`NN-英文短名.md`，如 `01-data-structures.md`、`05-replication.md`

### 节点粒度校准

判断一个节点粒度是否合适：
- 能用 1-2 句话说清这个节点要教什么 → 粒度合适
- 需要 5+ 句话才能说清 → 拆成多个节点
- 内容太薄，10 分钟就能讲完 → 合并到相邻节点

### 核心抽象表的写法

核心抽象表不是罗列功能特性，而是提取该系统的 **设计原语**——那些理解了之后能推导出其他设计决策的基本概念。

好的示例（Kafka）：
- Topic / Partition → 逻辑分组与物理分片
- Offset → 消费者自主管理的位置指针
- Consumer Group → 分区级负载均衡

坏的示例：
- "支持高吞吐" → 这是特性，不是抽象
- "Java 编写" → 这是实现细节，不是设计概念

### 依赖图的写法

```
01-基础概念
    ├── 02-存储设计
    ├── 03-复制机制
    ├── 04-生产者
    └── 05-消费者
              └── 06-集群管理（可并行）
                      └── 07-工程实践
```

规则：
- 箭头方向表示"学了 A 才能学 B"
- 标注"可并行"表示该节点可以和同级节点同时进行
- 不要过度制造依赖，大部分节点只依赖第一个基础概念节点

## 二、GAP_CHECK 阶段：权威知识对照

### 为什么需要 Gap Check

学习主题时最危险的不是"学错了"，而是"不知道还有什么没学"。Gap Check 通过对照权威源的完整知识列表，确保规划的节点覆盖了所有核心内容。

### 权威源优先级

1. **官方文档目录 / Getting Started / Design 文档** — 最权威
2. **官方教程 / Tutorial** — 次之
3. **经典教材目录**（如《DERTA》《CSAPP》）— 适用于基础学科
4. **高质量技术博客系列**（如 Martin Kleppmann、Jay Kreps）— 适用于特定领域

### Gap Check 流程

1. 用 WebFetch 获取权威源的完整章节/概念列表
2. 逐项对照已规划的主干道节点
3. 对每个未覆盖的项，分类标注：

| 分类 | 含义 | 示例 |
|------|------|------|
| `已覆盖` | 在某个节点中包含 | — |
| `进阶/超纲` | 超出当前学习目标 | "Kafka Streams API" |
| `前置缺失` | 需要先补其他知识 | "需要先了解 TCP" |
| `不需要` | 对理解核心概念非必要 | "历史版本兼容性" |
| `补入` | 应该加入但遗漏了 | "零拷贝机制" |

4. 如果有 `补入` 项：
   - 判断该内容应合并到已有节点还是新增节点
   - 更新 index.md 的节点列表
5. 将对照结果追加到 index.md

### 知识清单对照的格式

追加到 index.md 末尾：

```markdown
---

## 知识清单对照

> 权威源：<来源名称和链接>
> 对照日期：YYYY-MM-DD

| 权威源章节/概念 | 覆盖情况 | 说明 |
|----------------|----------|------|
| 概念 A | 已覆盖（节点 01） | — |
| 概念 B | 进阶/超纲 | 属于高级用法，当前不覆盖 |
| 概念 C | 补入（节点 03） | 原规划遗漏，已补入存储设计节点 |
```

### Gap Check 的关键心态

- **有意识地排除** 比 **无意识地遗漏** 好一万倍
- 排除不可怕，但必须记录为什么排除
- 如果权威源获取失败（网页不可访问），明确记录："未能获取 X 的完整目录，Gap Check 可能不完整"
