## 🎯 今日进行中 (WIP 限制: 核心任务不超过2个)
```dataview
TABLE priority AS "优先级", domain AS "任务域","<progress value='" + progress + "' max='100'></progress> " + progress + "%" AS "推进状态", deadline AS "DDL"
FROM "工作管理/Inbox-Task池" 
WHERE type = "task" 
AND started_date != null
AND started_date <= this.date 
AND (status = "doing" OR completed_date > this.date)
SORT priority ASC, deadline ASC
```
