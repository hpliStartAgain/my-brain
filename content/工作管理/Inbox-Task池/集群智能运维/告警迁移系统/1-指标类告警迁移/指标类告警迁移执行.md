# 指标类告警迁移执行

## 目标

将 Zabbix 中归类为「指标类」的告警规则，通过告警迁移系统转换为 Foxeye PromQL AlertRule，按组件分批完成双跑验证。

## 外部依赖清单

| 依赖项 | 状态 | 说明 |
|---|---|---|
| Hadoop Exporter | ✅ 已上线 | 覆盖 NN/DN/RM/NM 核心指标 |
| HBase Exporter | ✅ 已上线 | 覆盖 RegionServer/Master 指标 |
| HS2 Exporter | ✅ 已上线 | 覆盖 HiveServer2/HMS 指标 |
| KDC Exporter | ✅ 已上线 | 覆盖 Kerberos KDC 指标 |
| Kafka JMX Exporter 优化 | ⏸️ backlog | Kafka broker/consumer 指标待优化 |
| Categraf procstat | 🔄 待铺开 | 进程级指标（依赖 [[Categraf全集群铺开]]） |
| Zabbix agent 覆盖度 | ❌ 待统计 | 见 [[Zabbix agent vs Categraf 覆盖度统计]] |

## 执行步骤

### 第一批：已具备 Prometheus 指标的组件（可直接转换）

1. [ ] HDFS 系列（NN/DN）：从 [[Zabbix规则迁移状态梳理与分类]] 提取指标类可迁移规则
2. [ ] YARN 系列（RM/NM）：同上
3. [ ] Hive 系列（HS2/HMS）：同上
4. [ ] HBase 系列：同上
5. [ ] KDC：同上
6. [ ] 每批通过告警迁移系统执行转换 → PromQL AlertRule
7. [ ] 在 Foxeye 导入规则，进入双跑阶段

### 第二批：依赖 Exporter 补齐的组件

8. [ ] 等待 Kafka JMX Exporter 优化完成 → 执行 Kafka 指标告警迁移
9. [ ] 等待 Categraf 铺开 → 执行 procstat 类指标告警迁移

### 第三批：派生 Exporter 建设需求

10. [ ] 对「阻塞-缺Exporter」的指标类规则，汇总缺失指标清单
11. [ ] 输出 [[Exporter建设需求汇总]] → 触发对应 Exporter 开发子任务

## 验收标准

- 第一批可迁移规则通过系统转换并导入 Foxeye
- 双跑验证期间漏报率为零
- 阻塞规则全部关联到对应 Exporter 建设任务
