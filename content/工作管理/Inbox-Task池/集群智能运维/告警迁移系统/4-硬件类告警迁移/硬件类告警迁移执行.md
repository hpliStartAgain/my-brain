# 硬件类告警迁移执行

## 目标

将 Zabbix 中归类为「硬件类」的告警规则（磁盘 SMART / RAID 卡 / IPMI），迁移为 Prometheus Exporter + Foxeye PromQL AlertRule。

## 前置依赖

| 依赖项 | 状态 | 说明 |
|---|---|---|
| [[smartctl-exporter 开发]] | ❌ 未启动 | 磁盘 SMART 指标采集 |
| [[raid-exporter 开发]] | ❌ 未启动 | RAID 卡状态指标采集 |
| ipmi-exporter | ❌ 未建设（H2） | IPMI 硬件状态，优先级低于磁盘/RAID |

## 执行步骤

1. [ ] 从 [[Zabbix规则迁移状态梳理与分类]] 提取硬件类规则清单
2. [ ] 等待 smartctl-exporter 开发完成 → 部署到磁盘型节点
3. [ ] 等待 raid-exporter 开发完成 → 部署到 MegaRAID 节点
4. [ ] 逐条规则转换为 Foxeye PromQL AlertRule
5. [ ] 双跑验证

## 验收标准

- 磁盘 SMART 告警在 Foxeye 上线
- RAID 卡告警在 Foxeye 上线
- 双跑验证漏报率为零
