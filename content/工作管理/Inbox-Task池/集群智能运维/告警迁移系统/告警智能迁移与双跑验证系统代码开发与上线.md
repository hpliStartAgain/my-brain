### Multi-Agent 规则转换流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant MA as Master Agent<br/>(DeepSeek-V3)
    participant CA as Converter Agent<br/>(DeepSeek-R1)
    participant MaA as Matcher Agent<br/>(DeepSeek-V3)
    participant DB as 数据库

    U->>MA: 发起转换请求（SSE 流式）
    MA->>MA: ReAct 规划执行路径
    MA->>CA: 下发转换任务（≤5条/批）
    CA->>CA: CoT 逐步推导 Zabbix 表达式语义
    CA-->>MA: 返回 Foxeye 格式配置
    MA->>MaA: 提交语义验证
    MaA->>MaA: 新旧规则语义打分
    MaA-->>MA: 验证结果（通过/拒绝）
    MA->>DB: 保存 conversion_task + rule_mapping
    MA-->>U: SSE 推送结果（含工具调用事件）
```

### 规则匹配三层策略

| 层次 | 方式 | 触发时机 |
|------|------|---------|
| L1 Fingerprint | 规则名称 + 阈值结构化匹配 | 定时 rule_sync_job 自动执行 |
| L2 LLM 语义 | Matcher Agent 语义打分 | Fingerprint 未命中时 |
| L3 手动 | 用户在规则管理页手动绑定 | L1/L2 均未命中时 |
