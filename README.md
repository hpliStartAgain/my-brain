# 汀的知识碎片 (Digital Garden)

基于 **Quartz v4** 构建的个人数字花园与知识库，托管于 Vercel。

这里沉淀了作者作为高级 Data Infra SRE 在生产一线躺坑、救火、重构系统的备忘录与 Runbook。

## 🪐 知识版图
- **计算机基础**：Linux 内核、Java 并发与运行时、Go 并发编程、AI 大模型底座等。
- **架构与基础设施**：海量数据计算（Spark/Flink）、云原生集群控制、分布式一致性理论等。
- **SRE与稳定性**：线上真实故障复盘、全链路可观测性建设等。

## 🛠️ 常用开发指令
- 启动本地开发服务（热重载）：`npx quartz build --serve`
- 执行全量静态构建：`npx quartz build`
- 自动格式化代码：`npm run format`

保持敏锐，持续观测。
